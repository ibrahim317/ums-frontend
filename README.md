# UMS Dashboard

A modular dashboard application for UMS student grades.

## Setup Instructions

1. Clone the repository
2. Install dependencies:
   npm install

3. Start the application:
   npm start

4. Open your browser and navigate to:
   http://localhost:3000

## Notes
- Ensure you have Node.js installed.
- The application uses a local SQLite database for caching which is automatically created on first run.
